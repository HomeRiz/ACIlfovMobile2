# Asset-uri pentru ecranul de lansare

Acest fisier a fost generat de sablonul Flutter/Xcode si a fost mutat in `USERCHECK` deoarece nu este necesar pentru build.

Ecranul de lansare poate fi personalizat prin inlocuirea imaginilor din directorul original `ios/Runner/Assets.xcassets/LaunchImage.imageset`.

Aceeasi modificare se poate face din Xcode prin deschiderea proiectului cu:

```bash
open ios/Runner.xcworkspace
```

In Xcode se selecteaza `Runner/Assets.xcassets` in navigatorul proiectului si se inlocuiesc imaginile dorite.
